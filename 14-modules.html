16 Module reference

A one-screen map of every file in driftscope/, what it does, where you’d touch it. Sized to be skimmable; depth lives in the chapters above.

16.1 Configuration & shared state

16.1.1 config.py — 178 lines

Defines Region, SimConfig, PRESETS, dataset IDs, file-system paths. Touch when: adding a new region, changing a default parameter, or switching dataset versions. Imported by every other module.

Key objects:

Name Type Purpose
PRESETS dict[str, Region] Named bboxes — sundarbans, hooghly_mouth, bay_of_bengal, etc.
SimConfig dataclass All knobs for a simulation run (particles, runtime, forcings, settling, Brownian)
CMEMS_DATASET_ID, ERA5_DATASET, TIDE_MODEL_NAME, etc. string constants Dataset IDs used by fetchers — single point of change for product upgrades
CURRENTS_DIR, WAVES_DIR, …, TRAJ_DIR Path constants Auto-created on import; never mkdir manually

16.2 Data fetchers

16.2.1 fetch.py — 143 lines

Downloads CMEMS surface currents. One function, fetch_currents(), called via python -m driftscope.fetch.

16.2.2 hycom.py — 174 lines

Downloads HYCOM ESPC-D-V02 surface currents via OPeNDAP byte-range subsetting. Output schema deliberately matches fetch.py so they’re interchangeable downstream. CLI: python -m driftscope.hycom.

16.2.3 stokes.py — 185 lines

Downloads ERA5 wave parameters (\(H_s\), \(T_m\), mwd) and computes Stokes drift in-place via stokes_from_waves(). Output has both raw wave fields and derived \(u_\text{st}, v_\text{st}\). CLI: python -m driftscope.stokes.

16.2.4 winds.py — 147 lines

Downloads ERA5 10 m winds (\(u_{10}, v_{10}\)). Reuses _date_lists from stokes.py since both query the same ERA5 catalog. CLI: python -m driftscope.winds.

16.2.5 tides.py — 245 lines

Predicts tidal currents from TPXO9-atlas-v5 via pyTMD. Most logic is the seven workarounds for pyTMD 3.x quirks (Chapter 13). Requires TIDE_MODEL_DIR in .env. CLI: python -m driftscope.tides.

16.2.6 sst.py — 120 lines

Downloads OSTIA L4 SST (Kelvin) via CMEMS. CLI: python -m driftscope.sst.

16.2.7 chlorophyll.py — 126 lines

Downloads Ocean Color CCI L4 chlorophyll-a (mg/m³) via CMEMS. CLI: python -m driftscope.chlorophyll.

16.2.8 drifters.py — 152 lines

Pulls GDP drifter tracks (CSV) from NOAA AOML’s ERDDAP. No auth required. CLI: python -m driftscope.drifters.

16.2.9 rivers.py — 92 lines

Helpers for Ganges-Brahmaputra-Meghna river-discharge climatology used in seasonal-comparison runs. Loads monthly mean discharge by river and exposes seasonal_label() for plot titling.

16.2.10 spm.py — 885 lines

Module 7: cluster-based regression for satellite-derived SPM. Pure NumPy + sklearn. CBR algorithm is complete; Sentinel-2 fetch and matchup ingest are stubbed. See Chapter 15.

16.2.11 aquamatch.py — 268 lines

Helpers for the AquaMatch v2 in-situ TSS + SiteSR Landsat reflectance matchup dataset (50 GB across nine .feather files). Used to train CBR on US estuaries; transferred to BoB scenes following Tian 2026’s pan-Arctic recipe.

16.3 Simulation core

16.3.1 simulate.py — 467 lines

The run loop. Three layers:

  1. combine_forcings() (line 47): build a single combined velocity NetCDF from CMEMS/HYCOM + Stokes + tides + winds.
  2. seed_disk() and seeding logic (lines 156–331): build the particle release cloud — disk, basin-fill, or caller-supplied (e.g. SPM-weighted).
  3. run_simulation() (line 165): hand the FieldSet to OceanParcels and execute the kernel chain.

Touch when: adding a new forcing (extend combine_forcings), changing the seeding pattern, or wiring a new kernel.

16.3.2 kernels.py — 147 lines

OceanParcels kernels:

  • stokes_settling_velocity() — Stokes’ law, returns m/s.
  • AdvectionRK4_Land() — RK4 with friendly land deletion.
  • Settling() — vertical advection by per-particle w_settle.
  • BrownianMotion2D() — sub-grid diffusion random walk.

Plus stubs for StokesDrift, Windage, etc., showing the pattern for adding a new kernel.

16.4 Diagnostics & visualization

16.4.1 diagnostics.py — 167 lines

Eulerian diagnostics — the same fields the GOFLOW figure shows: speed, \(\log|\nabla V|\), \(\zeta/f\), \(\delta/f\). Pure NumPy plus a plot_diagnostics() 2×2 panel renderer. The new scripts/sundarban_dynamics_snapshot.py extends this with a velocity-over-SST panel and an inset speed time-series.

16.4.2 viz.py — 113 lines

Trajectory-plot helpers:

  • load_trajectories(zarr_path) — open a Zarr trajectory archive.
  • traj_to_dataframe(ds) — flatten to a long-form pandas DataFrame (traj, time, lon, lat).
  • plot_traj(...) — matplotlib scatter with time-coloring.

16.4.3 animate.py — 238 lines

Frame-by-frame matplotlib animations — particle trails over a time-evolving velocity field. Used by the seasonal-comparison script (Chapter 21) to produce the GBM monsoon-vs-dry 4-panel comparison and the per-season standalone GIFs.

16.5 Run scripts

Each one is a standalone end-to-end pipeline that uses the modules. Touch them to do science; touch the modules to change capabilities.

Script Purpose
run_coupled_simulation.py All five forcings + settling + Brownian, seeded by SPM map.
drifter_validation.py Single-drifter validation run + LW skill score.
drifter_validation_compare.py CMEMS vs HYCOM A/B against the same drifter.
run_seasonal_dispersion.py Run the same SPM-weighted release four times (one per season).
build_seasonal_comparison.py 2×2 mosaic + per-season GIFs from the four runs.
spm_apply_sundarbans.py Apply CBR to a Sundarbans Sentinel-2 scene; produce SPM map for release.
plot_coupled_simulation.py Three-panel render of a coupled-run output.
sundarban_dynamics_snapshot.py The 4-panel GOFLOW-style figure.

16.6 Touch points

A small map of “what to change for each kind of work”:

Goal Files to touch
Add a new region preset config.py’s PRESETS
Bump a dataset version config.py’s constants
Add a new forcing field <new>.py fetcher + simulate.py combine_forcings
Add new per-particle physics kernels.py + simulate.py kernel chain
Change seeding pattern simulate.py lines 269–331
Plot a new view of a run viz.py (helpers) or a new scripts/plot_*.py
Animate a run animate.py
