14 Observations — SST, chlorophyll, drifters

The currents/wave/wind/tide datasets are forcings — they drive the simulation. The datasets in this chapter are observations — used for context (does the simulated plume align with the chlorophyll feature?), validation (does a real GDP drifter follow the simulated track?), or, in Module 7, initial conditions (where is sediment in the water now?).

Dataset Resolution Cadence Module
OSTIA L4 SST 0.05° daily sst.py
Ocean Color CCI L4 chlorophyll 4 km daily chlorophyll.py
GDP drifter tracks per-position hourly drifters.py

All three are CMEMS-distributed (except drifters, from NOAA AOML), and all three need only the same CMEMS auth as currents (or no auth, for drifters).

14.1 OSTIA L4 SST

The UK Met Office’s OSTIA (Operational Sea Surface Temperature and Sea Ice Analysis) is a daily, gap-filled, multi-sensor SST analysis. CMEMS distributes it as METOFFICE-GLO-SST-L4-NRT-OBS-SST-V2.

  • L4 means “gap-filled and merged” — no clouds, no orbital tracks, one number per cell.
  • 5 km global resolution.
  • Inputs: AVHRR, AMSR2, VIIRS, in-situ — fused via optimal interpolation.

For DriftScope, SST plays two roles:

  1. Front detection. \(\log_{10}|\nabla T|\) at OSTIA’s 5 km resolution reveals frontal structure that smoothed daily-mean velocity products miss. Used in the dynamics-snapshot figure (Chapter 20).
  2. Sanity check on currents. Eddies show up as cold (cyclonic) or warm (anticyclonic) cores in SST. If your simulated current map shows an eddy where SST shows nothing, one of them is wrong — usually the currents (resolution).

driftscope/sst.py:51 is a one-call CMEMS subset:

copernicusmarine.subset(
    dataset_id="METOFFICE-GLO-SST-L4-NRT-OBS-SST-V2",
    variables=["analysed_sst"],   # Kelvin
    minimum_longitude=lon_min, ..., maximum_latitude=lat_max,
    start_datetime=..., end_datetime=...,
    output_filename=..., output_directory=...,
)

Output:

data/sst/<region>_<start>_<end>_sst.nc:
  Variables: analysed_sst         (Kelvin)
  Coordinates: time, latitude, longitude (0.05°)
Tip

SST is in Kelvin, not Celsius. OSTIA’s analysed_sst is in K, and the units attribute says so. Subtract 273.15 to plot in °C — the dynamics-snapshot script does this explicitly. If you forget, your colorbar shows “300 K” and you wonder why the ocean is on fire.

14.2 Chlorophyll-a (Ocean Color CCI)

driftscope/chlorophyll.py downloads the CMEMS multi-sensor merged chlorophyll-a (cmems_obs-oc_glo_bgc-plankton_my_l4-multi-4km_P1D).

  • Inputs: MODIS Aqua/Terra, VIIRS-SNPP, OLCI-A/B (Sentinel-3).
  • 4 km global resolution.
  • MY (multi-year reanalysis) covers 1997–present with ~6-month lag.
  • NRT (near-real-time) covers the last ~30 days.

Chlorophyll is useful for biological context — river plumes carry nutrients that drive coastal blooms. A trajectory that ends up in a high- chlorophyll patch is consistent with the river-runoff release; one that ends in oligotrophic open water has dispersed beyond the productive zone. The chlorophyll field doesn’t go into the simulation but it helps interpret the output.

Output:

data/chlorophyll/<region>_<start>_<end>_chl.nc:
  Variables: CHL                  (mg m⁻³)
  Coordinates: time, latitude, longitude (4 km)
Warning

Cloud cover dominates daily chlorophyll. Even at L4, gaps from persistent monsoon clouds leave large white patches. Use 8-day or monthly composites for analysis (CMEMS provides those too); daily L4 is mostly useful for individual-event synoptic plots.

14.3 Global Drifter Program drifters

Real surface drifters drogued at 15 m, GPS-tracked, quality-controlled by NOAA AOML. The most credible single validation source for a Lagrangian model.

The drifter program archives ~30,000 drifter histories from the 1980s to today. We pull regional subsets via NOAA AOML’s ERDDAP server, which speaks plain HTTP and returns CSV — no auth required.

driftscope/drifters.py:52 builds a URL like:

https://erddap.aoml.noaa.gov/gdp/erddap/tabledap/drifter_hourly_qc.csv
?ID,time,latitude,longitude
&time%3E=2025-04-20T00:00:00Z
&time%3C=2025-06-01T23:59:59Z
&latitude%3E=19
&latitude%3C=23
&longitude%3E=87.5
&longitude%3C=92.5

(%3E= is URL-encoded >=, %3C= is <=.) The response is a CSV that pandas reads directly:

df = pd.read_csv(url, skiprows=[1])   # row 1 is units, skip
df = df.rename(columns={"latitude": "lat", "longitude": "lon"})
df["time"] = pd.to_datetime(df["time"])

Output:

data/drifters/<region>_<start>_<end>_drifters.csv:
  Columns: ID, time, lat, lon

Each ID is one drifter’s full hourly track within the bbox/time window.

Tip

Empty CSV is a valid result. The Bay of Bengal sees 0–5 active drifters in a typical month. If the URL returns no rows, ERDDAP responds with HTTP 404 (not 200 + empty body). The fetcher catches this and writes an empty CSV with the right headers, so the cache check still works on re-run.

14.3.1 Why GDP for validation

The drifter is drogued at 15 m. It tracks the 15-m current — close to the surface but not the very surface. CMEMS at 0.494 m and HYCOM at its surface level are also near-surface but not at 15 m. So a CMEMS-vs-drifter comparison has a 15-m model–data offset built in. In practice this is small (0.1° amplitude) compared to the 1/12° gridding error.

For a more rigorous validation, you’d want un-drogued drifters (they ride the very surface) — but those are noisier (windage matters) and there are far fewer in the BoB record.

The validation chapter (Chapter 19) walks through:

  1. Fetching one specific GDP drifter’s track.
  2. Running a DriftScope simulation seeded at the drifter’s release point/time.
  3. Computing the Liu–Weisberg skill score — a normalized error metric where 1.0 is perfect, 0.0 is “no skill better than zero velocity”, and >0.5 is generally usable.

Past validation results in this repo:

Currents Drifter LW skill
CMEMS 1/12° GDP 300534064293930, BoB 2025-04 0.701
HYCOM 1/25° same drifter 0.852

The improvement (+0.15) is exactly the kind of robust signal we hoped to see when adding HYCOM as a second currents source.

14.4 Convention: where data lives

All three observation modules write to typed subdirectories under data/:

data/sst/         OSTIA L4 SST netCDFs
data/chlorophyll/ Ocean Color CCI L4 netCDFs
data/drifters/    GDP CSVs

Filenames follow the same <region>_<start>_<end>_<kind>.{nc,csv} convention as currents and tides. This pattern is set in driftscope/config.py:13’s path constants and reused by every fetcher.

14.5 Summary

  • OSTIA L4 SST at 5 km, daily, gap-filled — for fronts, eddies, and the dynamics-snapshot figure.
  • CCI chlorophyll-a at 4 km, daily, multi-sensor merged — for biological context.
  • GDP drifters at hourly cadence — for validation against real Lagrangian particles.
  • All share the deterministic <region>_<start>_<end>_<kind> filename convention.
