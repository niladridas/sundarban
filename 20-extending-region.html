21  Adding a new region

22 Adding a new region

DriftScope is region-agnostic: the bbox is a parameter, not a constant. But adding a named region (so it shows up in the CLI choices and in PRESETS) is a one-file change. This chapter walks through it for a new delta — say the Mahanadi in eastern India.

22.1 The pattern

A region is just a Region dataclass entry in driftscope/config.py’s PRESETS dict. Existing entries:

PRESETS: dict[str, Region] = {
    "sundarbans": Region(
        "Sundarbans Delta", 88.0, 90.5, 21.0, 22.8,
        seed_lon=89.0, seed_lat=21.2,
    ),
    "northern_bay_of_bengal": Region(
        "Northern Bay of Bengal", 86.5, 92.5, 19.5, 23.0,
        seed_lon=89.5, seed_lat=20.5,
    ),
    "bay_of_bengal": Region("Bay of Bengal (broad)", 80.0, 95.0, 10.0, 23.0),
    "hooghly_mouth": Region(
        "Hooghly River Mouth", 87.8, 89.0, 21.2, 22.2,
        seed_lon=88.6, seed_lat=21.4,
    ),
    "gulf_stream": Region("Gulf Stream", -75.0, -60.0, 35.0, 44.0),
    "california": Region("California Current", -127.0, -117.0, 32.0, 42.0),
}

Each entry has:

Field Required Purpose
name yes Pretty label used in plot titles and filenames
lon_min, lat_min, lon_max, lat_max yes Bbox corners
seed_lon, seed_lat optional Default release point if bbox center is on land

22.2 Step 1 — pick the bbox

For Mahanadi, the river mouth is at ~86.7°E, 20.3°N. The shelf extends ~50 km offshore. A useful bbox spans a wide enough area for a 30-day particle plume to stay inside.

Rule of thumb: bbox size \(\geq\) peak speed × runtime × 1.5 in each direction. Bay of Bengal monsoon current ≈ 0.5 m/s × 30 days × 86400 = 1300 km. So at 20°N, ~12° in lon and lat. That’s basin-scale; for a local-shelf study a smaller bbox is fine because particles will leave it and DeleteOOB handles them.

For a local Mahanadi study:

"mahanadi": Region(
    "Mahanadi Delta", 86.0, 88.5, 19.5, 21.0,
    seed_lon=86.7, seed_lat=20.2,
),

22.3 Step 2 — add the entry

Edit driftscope/config.py:

PRESETS: dict[str, Region] = {
    # ... existing entries ...
    "mahanadi": Region(
        "Mahanadi Delta", 86.0, 88.5, 19.5, 21.0,
        seed_lon=86.7, seed_lat=20.2,
    ),
    # ... rest of dict ...
}

That’s it. The new region is now available as a CLI choice in every fetcher and the simulator:

python -m driftscope.fetch  --region mahanadi
python -m driftscope.simulate --region mahanadi

22.4 Step 3 — fetch and run

# Currents (CMEMS or HYCOM)
python -m driftscope.fetch --region mahanadi --days 14
python -m driftscope.hycom --region mahanadi --start 2025-08-01 --end 2025-08-15

# Optional forcings
python -m driftscope.stokes --region mahanadi --days 14
python -m driftscope.winds  --region mahanadi --days 14
python -m driftscope.tides  --region mahanadi --days 14

# Run a basic simulation
python -m driftscope.simulate --region mahanadi --days 10

All cached as mahanadi_delta_<dates>_<kind>.{nc,csv} — no overwrite of existing Sundarbans data.

22.5 Step 4 — check the bbox isn’t broken

A few things can go subtly wrong with a new region:

Warning

Mostly land. If the bbox is mostly land, particles can’t be seeded. Inspect the currents file:

import xarray as xr
import matplotlib.pyplot as plt
ds = xr.open_dataset("data/currents/mahanadi_delta_<dates>.nc")
ds.uo.isel(time=0).plot()
plt.savefig("mahanadi_check.png")

The white pixels are land. If the bbox is >70% white, your seed disk needs to be offshore of the bbox center. Set seed_lon, seed_lat accordingly.

Warning

Bbox crosses the antimeridian (Pacific). HYCOM uses 0..360 longitude; CMEMS uses -180..180. The fetchers handle one wrap each but not bboxes that cross 0/360 (lon -178 to +178). Pick a bbox that stays on one side. Look at driftscope/hycom.py:71 for the explicit NotImplementedError.

Warning

Equatorial regions. \(f \to 0\) at the equator, so \(\zeta/f\) and \(\delta/f\) in the dynamics snapshot blow up. The diagnostics module masks this with f_safe = np.where(np.abs(f) < 1e-10, np.nan, f). For a region that includes the equator (e.g. Indonesian throughflow), the dynamics figure shows NaN there — correct, not a bug.

22.6 Step 5 — region-specific tuning

Different regions warrant different defaults. A few knobs to consider adjusting:

  • Brownian \(K_h\): 100 m²/s is BoB-tuned. Ekman-current-dominated regions (Pacific equatorial) need lower; eddy-rich regions (Kuroshio, Gulf Stream) need higher. Validate against drifters.
  • Settling diameter: 10 µm is silt for the BoB. Flocculated organic muds (e.g. Mississippi delta) settle slower; coarser shelf sands settle faster. Tune to your sediment.
  • Windage coefficient: 2% is sediment-laden water. Plastic debris is 3%; oil slicks 3.5%. Match to your tracer.
  • Tide model: TPXO9-atlas-v5 has good local refinement near major coastlines. For polar regions or Arctic shelves, FES2014 or the AOTIM regional models are better. Change TIDE_MODEL_NAME in config.py:139.

These are per-run parameters, not per-region — but a wrapper script that sets sensible defaults for each named region is a useful pattern. See scripts/run_seasonal_dispersion.py:36–49 for the BoB defaults bundled into one script.

22.7 Step 6 — share the work

Once a new region is working:

  1. Validate with at least one GDP drifter (Chapter 19).
  2. Document the choice of defaults — Brownian \(K_h\), settling diameter, etc. — in a memory file or comment.
  3. Commit the config.py entry along with a short script that exercises it. Future-you (or your student) will need to find the “happy path” for the new region.

22.8 Other “regions” — non-geographic

The pattern works for non-geographic modes too. For example:

  • gulf_stream in the existing presets is a non-Sundarbans region used for testing CMEMS and HYCOM behavior in a known-energetic environment.
  • A test preset with a tiny bbox could be added for unit tests that need real data without a 5-minute download.

The point is: PRESETS is a registry of named experiments. Use it for whatever named experiment makes sense.

22.9 Summary

  • A new region is one entry in PRESETS.
  • Once added, it works in every fetcher and the simulator.
  • Watch for mostly-land bboxes, antimeridian crossings, and equatorial Coriolis singularities — three documented gotchas.
  • Region-specific physics defaults (Brownian, settling) belong in a per-region wrapper script, not in config.py.
