DriftScope

Lagrangian transport in the Bay of Bengal — a reading guide

A complete walk-through of how the Sundarbans / Bay of Bengal drift model works — physics, data, code — written for a student stepping into the project for the first time.

Author

DriftScope contributors

Published

May 7, 2026

Note

This book is a tutorial. It explains what DriftScope does, why the code is shaped the way it is, and how to extend it. Read it linearly the first time, then jump around as a reference.

What you’re looking at

DriftScope is a small modular stack that answers one question repeatedly: given an ocean and a release point, where does the stuff go? “Stuff” is sediment, plastic, larvae, an oil slick, a search-and-rescue target — anything that moves with the surface flow. The whole project is one equation:

\[ \frac{d\mathbf{X}}{dt} = \underbrace{\mathbf{u}_\text{currents}}_{\text{CMEMS / HYCOM}} + \underbrace{\mathbf{u}_\text{Stokes}}_{\text{ERA5 waves}} + \underbrace{\mathbf{u}_\text{tides}}_{\text{TPXO9}} + \underbrace{\alpha\,\mathbf{u}_{10}}_{\text{ERA5 winds}} + \underbrace{\mathbf{w}_\text{settle}}_{\text{Stokes' law}} + \underbrace{\boldsymbol{\eta}_t}_{\text{Brownian}} \tag{1}\]

Eq. 1 is the spine. Each term is one chapter in the Physics part of this book; each is one self-contained module under driftscope/. The architecture choice is: build the spine, bolt on terms.

How to read this book

If you are…

  • new to oceanography — start with Chapter 5 and read Physics in order. The math is undergraduate-level vector calculus; we build intuition before formalism.
  • new to the codebase but comfortable with the physics — skim Physics, then go to Modules (Chapter 16) for the file-by-file reference, then Tutorials to run things.
  • here to extend the project — read the relevant Physics chapter, the matching module reference, then Chapter 23 which walks through adding a new term to Eq. 1 end-to-end.
  • here to evaluate the model — Validation lives in the drifter comparison tutorial and the drifter-validation Python scripts under scripts/.

What this book is not

  • Not a textbook on physical oceanography. We assume comfort with \(\mathbf{u} = (u, v)\), partial derivatives, and the idea of a velocity field. Anything beyond that we explain when it comes up.
  • Not API documentation. Every public function in driftscope/ has a docstring; this book teaches you how the pieces fit, not the signature of every helper.
  • Not exhaustive. We trade completeness for a clear path. Edges — model internals, second-order effects, alternative algorithms — get a footnote pointing to the relevant paper or commit.

Conventions

  • File references look like driftscope/simulate.py:165 — line numbers are stable to within a few lines if the file has been edited since the book was written.
  • Code blocks beginning with python are runnable; you can copy-paste them into a notebook in the project root after conda activate driftscope.
  • Callouts:
    • Why — a design decision worth understanding.
    • Caveat — a place the model lies, or where the data is thinner than it looks.
    • Try it — small exercise. Five-to-fifteen minutes.

Project at a glance

sundarban/
├── driftscope/             one Python package, one module per physics term
│   ├── config.py           regions, paths, dataset IDs, SimConfig
│   ├── fetch.py            CMEMS surface currents
│   ├── hycom.py            HYCOM ESPC-D-V02 currents (independent A/B)
│   ├── stokes.py           ERA5 waves → Stokes drift
│   ├── tides.py            TPXO9 via pyTMD
│   ├── winds.py            ERA5 10m winds (windage)
│   ├── sst.py              OSTIA L4 SST
│   ├── chlorophyll.py      CCI L4 chlorophyll-a
│   ├── drifters.py         GDP drifter tracks (validation)
│   ├── spm.py              Module 7: Sentinel-2 → SPM via cluster-based regression
│   ├── kernels.py          Parcels kernels (settling, Brownian, advection wrappers)
│   ├── simulate.py         the run loop — combines forcings, runs Parcels
│   ├── diagnostics.py      Eulerian diagnostics (∇V, ζ/f, δ/f)
│   ├── viz.py              plot helpers
│   └── animate.py          frame-by-frame animations
├── scripts/                end-to-end run scripts (validation, seasonal, coupled)
├── data/                   cached data (gitignored except for small samples)
├── notebooks/              one quickstart notebook
└── app.py                  Streamlit dashboard

The book mirrors this structure: one chapter per non-trivial module, plus the cross-cutting Physics and Tutorials parts.

Acknowledgments

This project exists because of decades of public ocean data and open-source infrastructure. Major debts: the Copernicus Marine Service for currents and SST; ECMWF and the Climate Data Store for ERA5; the OSU TPXO project for tides; NOAA AOML for the Global Drifter Program; the OceanParcels team for the Lagrangian framework the simulation runs on.

The structural inspiration is Lenain et al. (2026)’s GOFLOW: a single physics equation, one term at a time, validated against drifters. We follow the same recipe at coarser resolution.

Lenain, L. et al. (2026). GOFLOW: Geostationary ocean flow. Nature Geoscience. https://doi.org/10.1038/s41561-026-01943-0
