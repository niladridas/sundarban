18 Tutorial 2 — All forcings together

Goal: run the same Sundarbans setup as Tutorial 1 but with the full master equation. Compare with-vs-without each forcing to see what each term contributes. ~45 minutes including downloads.

18.1 Step 0 — preconditions

  • data/currents/sundarbans_2025-01-15_2025-01-29.nc already exists from Tutorial 1. (If not, fetch it first.)
  • .env has CDSAPI_KEY for ERA5 (waves and winds).
  • Optionally, TIDE_MODEL_DIR for tides; this tutorial works without tides but is more interesting with them.

18.2 Step 1 — fetch the additional forcings

# Waves (ERA5; ~30 s)
python -m driftscope.stokes \
    --bbox 88,21,90.5,22.8 \
    --start 2025-01-15 --end 2025-01-29 \
    --region sundarbans

# Winds (ERA5; ~30 s)
python -m driftscope.winds \
    --bbox 88,21,90.5,22.8 \
    --start 2025-01-15 --end 2025-01-29 \
    --region sundarbans

# Tides (pyTMD; instant after one-time TPXO setup)
python -m driftscope.tides \
    --bbox 88,21,90.5,22.8 \
    --start 2025-01-15 --end 2025-01-29 \
    --region sundarbans

You now have:

data/currents/sundarbans_2025-01-15_2025-01-29.nc
data/waves/sundarbans_2025-01-15_2025-01-29_waves.nc
data/winds/sundarbans_2025-01-15_2025-01-29_winds.nc
data/tides/sundarbans_2025-01-15_2025-01-29_tides.nc
Note

Skip tides: if you don’t have TPXO, drop the --tides flag below. The simulation runs fine without; you just lose the dominant signal in shelf regions.

18.3 Step 2 — run the coupled simulation

python -m driftscope.simulate \
    --currents data/currents/sundarbans_2025-01-15_2025-01-29.nc \
    --particles 500 \
    --days 10 \
    --seed-lon 89.0 --seed-lat 21.2 --seed-radius 0.15 \
    --stokes data/waves/sundarbans_2025-01-15_2025-01-29_waves.nc \
    --tides data/tides/sundarbans_2025-01-15_2025-01-29_tides.nc \
    --winds data/winds/sundarbans_2025-01-15_2025-01-29_winds.nc \
    --windage 0.02 \
    --settle --settle-diameter-um 10

What’s new:

Flag Adds
--stokes <file> Stokes drift from ERA5 waves
--tides <file> Barotropic tides from TPXO9
--winds <file> ERA5 10 m winds (multiplied by --windage)
--windage 0.02 2% — typical for sediment-laden water
--settle Enable Stokes settling (Module 5)
--settle-diameter-um 10 10 µm silt-class quartz

Console output (truncated):

· forcings: currents + Stokes×1.0 + tides + wind×2.0%
· settling: 10.0µm @ 2650 kg/m³ → w_s = 0.0905 mm/s (7.82 m/day)
· loading currents: sundarbans_2025-01-15_2025-01-29__stokes1.0_tides_wind2.0pct.nc
· seeded 500/500 particles at (89.000, 21.200) r=0.15°
→ running 10d, dt=30min, save every 180min

Output: data/trajectories/sundarbans_2025-01-15_2025-01-29__stokes1.0_tides_wind2.0pct__settle10um_traj.zarr/

18.4 Step 3 — overlay vs Tutorial 1

import xarray as xr
import matplotlib.pyplot as plt
from driftscope.viz import load_trajectories, traj_to_dataframe

# CMEMS-only baseline from Tutorial 1
ds_basic = load_trajectories(
    "data/trajectories/sundarbans_2025-01-15_2025-01-29__currents_only_traj.zarr"
)
df_basic = traj_to_dataframe(ds_basic)

# Coupled run
ds_coup = load_trajectories(
    "data/trajectories/sundarbans_2025-01-15_2025-01-29"
    "__stokes1.0_tides_wind2.0pct__settle10um_traj.zarr"
)
df_coup = traj_to_dataframe(ds_coup)

fig, ax = plt.subplots(figsize=(9, 8))

# Tutorial 1: faint
for tid, grp in df_basic.groupby("traj"):
    ax.plot(grp.lon, grp.lat, color="steelblue", lw=0.5, alpha=0.10)
last_basic = df_basic.groupby("traj").tail(1)
ax.scatter(last_basic.lon, last_basic.lat, color="steelblue",
           s=12, alpha=0.6, label="CMEMS only (day 10)")

# Coupled: prominent
for tid, grp in df_coup.groupby("traj"):
    ax.plot(grp.lon, grp.lat, color="crimson", lw=0.5, alpha=0.10)
last_coup = df_coup.groupby("traj").tail(1)
ax.scatter(last_coup.lon, last_coup.lat, color="crimson",
           s=12, alpha=0.8, label="all forcings + settling (day 10)")

ax.set_xlim(88, 90.5); ax.set_ylim(21, 22.8)
ax.legend(); ax.set_title("Effect of full forcing set vs CMEMS-only")
plt.savefig("data/tutorial2_overlay.png", dpi=150, bbox_inches="tight")

What you should see:

  • Tides smear the trajectory along an axis. Particles oscillate ±5–10 km tidally over each 12.4-h cycle while drifting with the residual. In a low-frequency plot the coupled cloud will look noisier along the principal tidal axis.
  • Windage shifts the cloud downwind. January NE monsoon winds push particles toward the SW more strongly than CMEMS alone.
  • Settling thins the cloud progressively. Particles below ~30 m experience much weaker horizontal drift; the cloud at day 10 is narrower with settling on.

The differences are real but subtle in dry season. Re-run with monsoon-season dates (e.g. --start 2025-08-01 --end 2025-08-15) and the differences become huge.

18.5 Step 4 — break out each forcing’s contribution

What if you want to know how much each term contributed? Run five times: baseline, baseline + each one term, full coupled.

Tip

Cache works in your favor. combine_forcings() builds a unique filename for each forcing combination (“__stokes1.0_tides”, “__wind2.0pct”, etc.) and caches the combined NetCDF. The five-runs matrix only re-runs the integrator, not the data combine.

# Currents only (already from Tutorial 1)
# … no extra flags …

# Currents + Stokes
python -m driftscope.simulate ... --stokes data/waves/...waves.nc

# Currents + tides
python -m driftscope.simulate ... --tides data/tides/...tides.nc

# Currents + windage
python -m driftscope.simulate ... \
    --winds data/winds/...winds.nc --windage 0.02

# All four
python -m driftscope.simulate ... --stokes ... --tides ... --winds ...

Then plot the day-10 mean position of each ensemble:

import numpy as np

stems = [
    ("CMEMS only",                  "currents_only"),
    ("+ Stokes",                    "stokes1.0"),
    ("+ tides",                     "tides"),
    ("+ wind 2%",                   "wind2.0pct"),
    ("all forcings",                "stokes1.0_tides_wind2.0pct"),
]

means = []
for label, suffix in stems:
    path = (f"data/trajectories/sundarbans_2025-01-15_2025-01-29"
            f"__{suffix}_traj.zarr")
    ds = load_trajectories(path)
    df = traj_to_dataframe(ds)
    last = df.groupby("traj").tail(1)
    means.append((label,
                  float(last.lon.mean()),
                  float(last.lat.mean())))

for label, x, y in means:
    print(f"{label:25s} → ({x:.4f}°E, {y:.4f}°N)")

You’ll get something like:

CMEMS only                → (88.7821°E, 21.0334°N)
+ Stokes                  → (88.7619°E, 21.0291°N)
+ tides                   → (88.7894°E, 21.0455°N)
+ wind 2%                 → (88.7102°E, 20.9742°N)
all forcings              → (88.6708°E, 20.9588°N)

This is the “term contribution” table. Windage moves the mean by ~7 km in this dry-season setup; Stokes by ~2 km; tides barely shift the mean (they are oscillatory) but spread the cloud.

18.6 What you’ve learned

  • The coupled simulation is one extra flag per forcing — there is no special API.
  • The combined-NetCDF cache makes A/B testing efficient.
  • Tides oscillate, currents and wind drift, settling thins. Each forcing has a distinctive signature you can read off the trajectory cloud.
  • The dry-season Sundarbans is a mild flow regime; reality gets much more interesting in monsoon and post-cyclone conditions.

18.7 What’s still missing

Two big things:

  1. Sub-grid eddies. All five terms above are deterministic. Real ocean trajectories have ~10 km RMS scatter per day from unresolved submesoscale motion. Add --brownian-kh 100 to the simulation; the final cloud broadens by ~20 km after 10 days. The next tutorial (Chapter 19) checks whether 100 m²/s is the right number by comparing against a real GDP drifter.
  2. Reality. All of this is model output. We haven’t compared with a single observation. Tutorial 3 fixes that.
