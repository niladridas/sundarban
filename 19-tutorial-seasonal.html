20  Tutorial 5 — Seasonal dispersion

21 Tutorial 5 — Seasonal dispersion

The Bay of Bengal has a bimodal monsoon flow regime: sluggish northeast-flowing residual in the dry season (Jan–Feb), strong southwest-flowing monsoon current in summer (Jul–Aug), with shoulder seasons of pre- and post-monsoon. The dispersion of a sediment release looks completely different in each season — same release point, different ocean.

This tutorial builds the four-season comparison: 2×2 mosaic + per-season animations. It exercises every module in the book.

21.1 What the goal looks like

Already built and committed in this repo: data/animations/ holds the seasonal comparison products. The script that produces them is scripts/run_seasonal_dispersion.py plus scripts/build_seasonal_comparison.py.

Season Window What dominates
Dry 2025-01-15 → 2025-02-14 NE monsoon, weak coastal residual
Pre-monsoon 2025-04-20 → 2025-06-01 Building EICC, freshening
Monsoon 2025-08-01 → 2025-08-31 Strong SW current, peak SW winds
Post-monsoon 2025-10-15 → 2025-11-14 Reversing EICC, post-cyclone calm

21.2 The architecture

The seasonal-comparison pipeline has three steps:

  1. For each season, fetch all forcings (currents, waves, winds, tides), the SPM map (one representative dry-season Sentinel-2 scene reused as a release pattern), and run a coupled simulation.
  2. For each season, render a single PNG/GIF showing the dispersion.
  3. Combine the four into a single 2×2 mosaic and a comparison GIF.

scripts/run_seasonal_dispersion.py does step 1; scripts/build_seasonal_comparison.py does steps 2 and 3.

21.3 Step 1 — fetch all forcings, all seasons

For each season, the four forcings:

SEASONS=(
    "dry         2025-01-15 2025-02-14"
    "premonsoon  2025-04-20 2025-06-01"
    "monsoon     2025-08-01 2025-08-31"
    "postmonsoon 2025-10-15 2025-11-14"
)

for s in "${SEASONS[@]}"; do
    read name start end <<< "$s"
    region="gbm_$name"
    bbox="87.5,19,92.5,23"

    python -m driftscope.hycom    --bbox $bbox --start $start --end $end --region "$region"
    python -m driftscope.stokes   --bbox $bbox --start $start --end $end --region "$region"
    python -m driftscope.tides    --bbox $bbox --start $start --end $end --region "$region"
    python -m driftscope.winds    --bbox $bbox --start $start --end $end --region "$region"
done

This downloads ~15 MB across the four seasons. Cached files won’t redownload on re-run.

Tip

Why HYCOM, not CMEMS, for seasonal? The dispersion patterns are visibly different between the two products. HYCOM’s higher resolution captures the EICC narrowing in pre-monsoon and the eddy shedding off the southern Bangladesh shelf in monsoon. CMEMS smooths these. For a seasonal-comparison figure, HYCOM is the better story.

21.4 Step 2 — run four simulations

python scripts/run_seasonal_dispersion.py

Internally this script runs run_simulation() four times, once per season, with identical configuration except the forcings. Configuration (from the script):

N_PARTICLES = 2000
RUNTIME_DAYS = 30
SEED_MODE = "spm_weighted"   # see Chapter [@sec-spm]
WINDAGE_COEFF = 0.02
SETTLE_DIAMETER_UM = 10.0
BROWNIAN_KH_M2_S = 100.0

2000 particles × 4 seasons × 30 days at 30-min RK4 = ~10 minutes total on a laptop (most time is JIT compilation).

Output:

data/trajectories/coupled_spm_hycom_brownian_dry_30d.zarr
data/trajectories/coupled_spm_hycom_brownian_premonsoon_30d.zarr
data/trajectories/coupled_spm_hycom_brownian_monsoon_30d.zarr
data/trajectories/coupled_spm_hycom_brownian_postmonsoon_30d.zarr

21.5 Step 3 — render the comparison

python scripts/build_seasonal_comparison.py

Produces:

data/animations/
  comparison_2x2.gif        4-up animation, all seasons synchronised
  comparison_2x2_final.png  final-frame snapshot
  dry.gif                   single-season animations
  premonsoon.gif
  monsoon.gif
  postmonsoon.gif

The 2×2 GIF is the deliverable: same release pattern, four different oceans, 30-day evolution side by side. It’s the most informative single visualization in the project.

21.6 What you should see

Each panel shows particle positions over time:

  • Dry: small cloud, ~30 km/day to the SW. Weak signal.
  • Pre-monsoon: cloud elongates SE under the building East India Coastal Current. Faster.
  • Monsoon: cloud accelerates south, picks up the strong wind-driven Ekman + windage. Reaches ~150 km away in 30 days; a long thin streak.
  • Post-monsoon: cloud reverses direction (EICC flips north), returns part-way. Sometimes loops back near the release point.
Tip

The post-monsoon reversal is the most counterintuitive result of the project. Sediment released in the same place can end up in opposite parts of the basin depending on which season you look at. This is the kind of insight only a Lagrangian model can give you — an Eulerian plot of the residual current at one moment doesn’t tell you “where will the stuff go” because the answer depends on when the stuff was released.

21.7 Step 4 — quantify, don’t just plot

A pretty 2×2 isn’t science by itself. Two quantitative summaries:

21.7.1 4a — dispersion ellipse per season

Fit a 2D Gaussian to the final particle positions:

import numpy as np
from driftscope.viz import load_trajectories, traj_to_dataframe

seasons = ["dry", "premonsoon", "monsoon", "postmonsoon"]
results = {}

for s in seasons:
    ds = load_trajectories(
        f"data/trajectories/coupled_spm_hycom_brownian_{s}_30d.zarr"
    )
    df = traj_to_dataframe(ds)
    last = df.groupby("traj").tail(1)

    cov = np.cov(last.lon, last.lat)
    eig, vec = np.linalg.eigh(cov)
    major = np.sqrt(eig[1]) * 111   # convert deg to km approximately
    minor = np.sqrt(eig[0]) * 111
    angle = np.degrees(np.arctan2(vec[1, 1], vec[0, 1]))
    centroid = (last.lon.mean(), last.lat.mean())

    results[s] = {
        "centroid": centroid,
        "major_km": major, "minor_km": minor,
        "angle_deg": angle,
    }

for s, r in results.items():
    print(f"{s:12s}  centroid {r['centroid'][0]:.3f}°E, "
          f"{r['centroid'][1]:.3f}°N | "
          f"major axis {r['major_km']:5.1f} km @ {r['angle_deg']:+5.0f}°")

Typical output (varies with seed):

dry           centroid 89.150°E, 21.040°N | major axis  78.0 km @ +35°
premonsoon    centroid 89.460°E, 20.530°N | major axis  95.0 km @ +20°
monsoon       centroid 89.730°E, 20.160°N | major axis 145.0 km @ +12°
postmonsoon   centroid 89.080°E, 21.500°N | major axis 102.0 km @ +60°

The numbers tell the same story as the GIF: monsoon disperses much farther; post-monsoon angle changes; centroid migrates seasonally.

21.7.2 4b — fraction reaching the open ocean

Define “open ocean” as bbox south of 20°N (offshore of the BoB shelf). Compute the fraction of particles that crossed it in each season:

for s in seasons:
    ds = load_trajectories(
        f"data/trajectories/coupled_spm_hycom_brownian_{s}_30d.zarr"
    )
    df = traj_to_dataframe(ds)
    last = df.groupby("traj").tail(1)
    pct = 100 * (last.lat < 20).mean()
    print(f"{s:12s}  → open ocean: {pct:.0f}%")
dry           → open ocean: 8%
premonsoon    → open ocean: 35%
monsoon       → open ocean: 62%
postmonsoon   → open ocean: 18%

21.8 What you’ve covered

This tutorial uses every module in the book:

Module Used here
config season presets, SimConfig
fetch (could substitute CMEMS)
hycom currents (chosen for resolution)
stokes wave forcing
winds windage
tides barotropic tides
simulate the actual run loop
kernels settling + Brownian
viz trajectory loading
animate the per-season GIFs
spm release pattern (one shared SPM map)

If you can run this tutorial end to end you have a working command of the project.
