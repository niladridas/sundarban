4 Quickstart

Five commands. End-to-end. The point is to confirm the stack works on your machine before you read about why it works.

4.1 The five commands

# 1) Currents for the default region (Sundarbans, last 14 days)
python -m driftscope.fetch

# 2) Run a 500-particle, 10-day simulation
python -m driftscope.simulate

# 3) Render a quick-look plot
python -c "
from pathlib import Path
import xarray as xr, matplotlib.pyplot as plt
from driftscope.viz import load_trajectories, traj_to_dataframe

ds = load_trajectories(sorted(Path('data/trajectories').glob('*.zarr'))[-1])
df = traj_to_dataframe(ds)
plt.scatter(df.lon, df.lat, s=1, c=df.time.astype('int64'),
            cmap='magma', alpha=0.4)
plt.savefig('data/quickstart_traj.png', dpi=150, bbox_inches='tight')
print('saved data/quickstart_traj.png')
"

# 4) (Optional) Launch the interactive dashboard
streamlit run app.py

If data/quickstart_traj.png shows a plume of dots seeded near the Sundarbans coast and spreading offshore, you have a working install.

4.2 What just happened

Let’s unpack each step.

4.2.1 Step 1 — fetch currents

python -m driftscope.fetch resolves to driftscope/fetch.py’s main(). It reads the default region from driftscope/config.py:

"sundarbans": Region(
    "Sundarbans Delta", 88.0, 90.5, 21.0, 22.8,
    seed_lon=89.0, seed_lat=21.2,
),

…and downloads CMEMS surface currents (variables uo, vo) for that bbox over the trailing 14 days, using the copernicusmarine Python client. Output:

data/currents/sundarbans_delta_<start>_<end>.nc

The file holds two velocity components on a (time, latitude, longitude) grid at 1/12° (≈ 8 km) resolution, daily means.

Tip

Caching by filename. output_path() builds a deterministic name from (region, start, end). If you re-run the command, it sees the file already exists and skips the download. To force a refetch, pass --force.

4.2.2 Step 2 — run a simulation

python -m driftscope.simulate calls driftscope/simulate.py:165’s run_simulation(). With no arguments it picks the most recently fetched currents file, seeds 500 particles in a small disk around the region’s default release point, and integrates for 10 days using fourth-order Runge–Kutta (RK4) on the velocity field.

The output is a Zarr archive:

data/trajectories/sundarbans_delta_<start>_<end>__currents_only_traj.zarr/

Each particle is one row; each saved time step is one column. By default positions are saved every 3 hours over 10 days → 81 time steps.

4.2.3 Step 3 — quick plot

The one-liner uses load_trajectories() and traj_to_dataframe() from driftscope/viz.py to flatten the Zarr into a long-format pandas DataFrame, then a scatter on (lon, lat) colored by time.

The result is the simplest legitimate visualization of a Lagrangian simulation: every dot is one particle at one moment.

4.2.4 Step 4 — dashboard

app.py is a Streamlit app. The sidebar lets you change region, runtime, seed point, and forcings without touching the CLI; three tabs show drift trails, accumulation heatmap, and the underlying velocity field.

It’s a useful exploration tool but not where the work happens. The authoritative interface is the Python API.

4.3 What you can do next

Three productive directions, each one chapter of this book:

  1. Understand the physics — why does the trajectory bend the way it does? Start with Chapter 5.
  2. Add a forcing — currents alone miss tides, waves, and wind. Add them with the patterns in Chapter 8 and see how the trajectory changes.
  3. Validate against reality — overlay a real Global Drifter Program track on a simulated one and compute a skill score. Chapter 19.

4.4 Common quickstart issues

Note

copernicusmarine asks for credentials interactively. It means COPERNICUSMARINE_USERNAME and COPERNICUSMARINE_PASSWORD aren’t in your environment. Make sure you actually edited .env, and that load_dotenv() is finding it (run from the repo root).

Note

“All seed points landed on land/NaN.” Your seed disk is too close to shore. The Sundarbans default seed (89.0, 21.2) is offshore but small deviations land in the mangrove forest. Move the seed offshore (e.g. --seed-lat 20.8) or widen the disk with --seed-radius 0.4.

Note

Parcels prints a warning about where='out'. That’s a parcels v3 + numpy 2.x deprecation that is filtered in driftscope/simulate.py:19. If you see it, the filter line was edited or numpy was bumped — harmless, not your problem.
