17 Tutorial 1 — Your first simulation

Goal: run a CMEMS-only Lagrangian simulation in the Sundarbans, plot the trajectories, understand every parameter you set. ~20 minutes from the quickstart end-state.

17.1 Step 0 — preconditions

Assumes you’ve done Chapter 3 and have:

  • conda activate driftscope
  • .env with valid CMEMS credentials.
  • A working python -c "import parcels, copernicusmarine".

17.2 Step 1 — fetch currents

python -m driftscope.fetch \
    --bbox 88,21,90.5,22.8 \
    --start 2025-01-15 --end 2025-01-29 \
    --region sundarbans

This pulls 14 days of CMEMS daily-mean surface currents. Output: data/currents/sundarbans_2025-01-15_2025-01-29.nc. ~600 KB.

Tip

Why these dates? Mid-January 2025 is dry season: no monsoon freshening, no spring tropical cyclone, mostly weak coastal currents under NE monsoon winds. A clean baseline. We’ll reuse this to compare seasons later.

17.3 Step 2 — run a basic simulation

python -m driftscope.simulate \
    --currents data/currents/sundarbans_2025-01-15_2025-01-29.nc \
    --particles 500 \
    --days 10 \
    --seed-lon 89.0 \
    --seed-lat 21.2 \
    --seed-radius 0.15

What you just configured:

Flag Meaning
--currents Use this specific NetCDF (overrides “latest in dir”)
--particles 500 Release 500 particles
--days 10 Integrate for 10 days
--seed-lon, --seed-lat Center of the disk-shaped release
--seed-radius 0.15 Disk radius in degrees ≈ 16 km

Default dt is 30 min (RK4); default save cadence is 3 h. So you’ll get 81 saved time steps × 500 particles = 40,500 position records.

Output: data/trajectories/sundarbans_2025-01-15_2025-01-29__currents_only_traj.zarr/.

The console will print something like:

· loading currents: sundarbans_2025-01-15_2025-01-29.nc
· seeded 500/500 particles at (89.000, 21.200) r=0.15°
→ running 10d, dt=30min, save every 180min
INFO: Compiled JITKernel ...
100% ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 240/240 0:00:33
✓ trajectories: data/trajectories/...

17.4 Step 3 — open the trajectories

import xarray as xr
from driftscope.viz import load_trajectories, traj_to_dataframe

ds = load_trajectories(
    "data/trajectories/sundarbans_2025-01-15_2025-01-29__currents_only_traj.zarr"
)
df = traj_to_dataframe(ds)
print(df.head())
print(f"\n{df['traj'].nunique()} particles, "
      f"{df['time'].nunique()} time steps, "
      f"{len(df):,} total rows")

17.5 Step 4 — three plots

Each one shows the run from a different angle. Run all three; together they’re a good first impression.

17.5.1 Plot 1: trajectory bundle

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 7))

for traj_id, group in df.groupby("traj"):
    ax.plot(group.lon, group.lat, alpha=0.15, lw=0.6, color="navy")

# Release point and final positions
first = df.groupby("traj").head(1)
last = df.groupby("traj").tail(1)
ax.scatter(first.lon, first.lat, c="green", s=8, label="release")
ax.scatter(last.lon, last.lat, c="red", s=8, label="day 10")
ax.set_xlim(88.0, 90.5); ax.set_ylim(21.0, 22.8)
ax.set_xlabel("Longitude (°E)"); ax.set_ylabel("Latitude (°N)")
ax.legend()
ax.set_title("Dry-season Sundarbans drift, 10 days, CMEMS only")
plt.savefig("data/tutorial1_trajectories.png", dpi=150,
            bbox_inches="tight")

What to look for:

  • Direction: which way did particles go on average? In dry season the dominant flow is south-southwest (Indian winter coastal current).
  • Spread: how broad is the cloud at day 10? A coherent flow produces a tight cloud; a sheared flow produces a broad smear.

17.5.2 Plot 2: time-coloured scatter

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 7))
sc = ax.scatter(df.lon, df.lat, c=df.time.astype('int64'),
                cmap='magma', s=1.5, alpha=0.4)
plt.colorbar(sc, ax=ax, label='time')
ax.set_xlim(88.0, 90.5); ax.set_ylim(21.0, 22.8)
ax.set_title("Time-coloured particle positions, days 0–10")
plt.savefig("data/tutorial1_time_scatter.png", dpi=150,
            bbox_inches="tight")

The colorbar maps numerical time to color; dark = release, bright = day 10. Useful for spotting slow-vs-fast lobes within the cloud.

17.5.3 Plot 3: final-position heatmap

import numpy as np
import matplotlib.pyplot as plt

last = df.groupby("traj").tail(1)
H, xedges, yedges = np.histogram2d(
    last.lon, last.lat,
    bins=[40, 40], range=[[88, 90.5], [21, 22.8]],
)

fig, ax = plt.subplots(figsize=(8, 7))
im = ax.imshow(H.T, origin='lower', cmap='magma', aspect='auto',
               extent=[88, 90.5, 21, 22.8])
plt.colorbar(im, ax=ax, label='# particles in cell')
ax.set_title("Final particle density at day 10")
plt.savefig("data/tutorial1_density.png", dpi=150, bbox_inches="tight")

This is the operational answer: “if I released 500 particles here, where would they be 10 days later?” The heatmap binds 1:1 to a real-world question.

17.6 What you’ve shown

Three things, by demonstration:

  1. CMEMS-driven drift in the Sundarbans is steady but slow. Daily means smooth out the 12-h tidal oscillation; the residual is the wind-driven Ekman current.
  2. Even in 10 days with no random noise, dispersion happens. This is the shear-driven dispersion of Chapter 10. The cloud spreads because different particles sample slightly different velocities along the way.
  3. A 500-particle ensemble is enough to see the structure clearly. Going to 5,000 would reveal more cloud detail; 50 would be noisy. Pick a number that shows the answer without burning compute.

17.7 What’s missing

Compare what you just did with the master equation Eq. 5.2:

\[ \frac{d\mathbf{X}}{dt} = \mathbf{u}_\text{currents} + \underbrace{\mathbf{u}_\text{Stokes}}_{\text{missing}} + \underbrace{\mathbf{u}_\text{tides}}_{\text{missing}} + \underbrace{\alpha\,\mathbf{u}_{10}}_{\text{missing}} + \mathbf{w}_\text{settle} + \boldsymbol{\eta}_t \]

You’ve used only \(\mathbf{u}_\text{currents}\). The other four velocity terms are zero. For the Sundarbans this is a bad approximation — tides dominate the shelf flow, and you’re missing a huge piece of the truth.

The next tutorial puts them all in.

17.8 Try it: change one thing

Note

Try it — five-minute exercise. Re-run with --seed-mode bbox and --particles 2000. This switches from a small disk release to a “basin fill” — particles uniformly across all ocean cells. The trajectory bundle becomes a coastline-shaped sheet of particles, and you’ll see the coastal current as a coherent flow along the shelf break. This is one of the most useful release modes for “where does sediment from the shelf go?” questions.

Continue to Chapter 18 to add tides, waves, wind, settling, and Brownian noise — the full master equation.
